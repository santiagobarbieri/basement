- Wordmark: Santi's SVG from Desktop/BASEMENT/assets/Logo.svg. Geometry preserved;
  original pink fill changed to #C4C4C4 to match the supplied home reference.
- App icon: Santi's favicon.svg paths centered on a square dark background; native
  macOS icons generated by the Tauri icon tool.
- Albert Sans variable font: Santi's existing IDEAS project font asset. Bundled
  under the accompanying SIL Open Font License.
- Cooper BT Medium Italic: uses the locally installed CooperMdBT-Italic font
  (its local file is named CrusadeMdBT-Italic.ttf). Not embedded or redistributed.
  Other machines need the same licensed local font for exact typography.
